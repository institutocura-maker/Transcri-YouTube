## 2. Formato (compatível com `ferramentas/rc_docx.py`)

1. Título `## Bloco N — tema` (vira Heading 2 no `.docx`).
2. **Nenhum comentário HTML** dentro desta pasta.
3. Um turno de fala = um parágrafo; linha em branco separa parágrafos.
4. `**negrito**` para o rótulo do falante; `*itálico*` para títulos de obras.
5. O negrito de primeira menção é aplicado pelo montador via `--lexico`; não marcar à mão.
